# Modulo v0.1 release scope

The delivered repository is GitHub Pages-ready, but has not been published to a user-owned GitHub repository. Use the included Actions workflow and README to deploy. The supplied development preview runs the frontend with the optional Python service on one origin.

Browser-only conversion supports structured imports and executable explicit algorithms. OCR recognition is a local, best-effort pipeline, not a guaranteed reconstruction of every flowchart image. Uploaded images/PDFs require a separately running API and mandatory review. Missing or ambiguous paths are not replaced by guessed code.

Functional inspiration from FlowMapp includes graph shapes/connections, editable node appearance/notes, multiple local projects, source review and export. It does not include FlowMapp’s cloud collaboration, full icon library, sitemaps or hosted sharing. The project has no account, billing, purchase or external task-execution functionality.

All generated source should be reviewed and tested before reuse. Supported operations are finite numeric arithmetic, explicit assignments, inputs, outputs, binary decisions and loops. No network/file operations, method calls, arbitrary business-task synthesis or uploaded source execution are supported. JavaScript/Python use their standard floating-point and type semantics outside the documented portable subset.
